# split-rules.md — テロップ分割の詳細ルール

制作実例での確定運用（2026年・複数本の実制作で固まった）。

## 文字数（縦リール・vertical_reel）

| 状態 | 全角文字数 | 描画幅px（120px @2160幅） |
|---|---|---|
| 1行・**快適** | ≤ 12 | ≤ 1750 |
| 1行・限界 | ≤ 15 | ≤ 1900 |
| 横長（FAIL） | > 15 | > 1900 |

横長になったら：
1. **意訳して短縮**（「メンタルのアップダウン激しかった」→「アップダウン激しかった」）
2. **2行化**（行間×1.12・行間ピクセル数 = font_px × 1.12）

## 文字数（横講座・horizontal_lecture）

横は画面幅 2880px・サイズ 95px @1620高（size-ratio 0.058）：

| 状態 | 全角文字数 | 描画幅px |
|---|---|---|
| 1行・快適 | ≤ 20 | ≤ 2100 |
| 1行・限界 | ≤ 24 | ≤ 2400 |

## 表示時間（cps = 字数 ÷ 秒）

| 状態 | cps |
|---|---|
| 快適 | ≤ 6 |
| 通常 | ≤ 7 |
| 注意（WARN・要目視） | 7〜12 |
| 物理的に読めない（FAIL） | > 12 |

**畳み掛け**（同じ text が連続するとき・例：「ずっと隣で寝てくれた」を2回連続表示）は cps 検査の対象外。

## 分割の優先順位

長すぎるテロップを2つに割るとき、切る位置の優先：

1. **文末（です／ます／でした／ですよ／ますよ／ない／だ／だった 等）の直後**
2. **接続助詞（から／ので／くて／して／のに／けど 等）の直後**
3. **格助詞（が／を／に／で／と／は／も 等）の直後**
4. **読点的な「、」「。」が話し言葉に対応する位置**（あれば）
5. **意味の塊の境界**（名詞句の終わり等）

### 不可

- カタカナの連続途中で割る（例「メン｜タル」NG）
- 英数字の連続途中で割る（例「Cla｜ude」NG）
- 固有名詞の途中で割る（例「PowerPo｜int」NG）
- 数字の途中で割る（例「200｜ml」NG）

## 行頭NG

行頭に来ると違和感の出る文字：

```
ん っ ー ら り る れ ろ よ ね
```

これらが行頭に来ないよう、分割位置を1〜2文字前後にずらす。

**判定は「先頭の1文字」ではなく「先頭に来る実際の語（word 単位）」で行うこと。**
「もっと」「もちろん」「もしかしたら」「もう」「いくら」「いくつ」のように、
NG文字で始まる独立した語（助詞・活用の断片ではない語）はカード先頭に来ても問題ない。
1文字だけで判定すると「もっと活用できるんじゃんって」のような正常なカードを誤検出する
（2026-07 とく歯科案件でこの誤検出パターンが頻発、first token の実際の語で判定して解消）。

## カード先頭に来てはいけない語（境界＝前カードとの間のみ・内部の2行目改行は対象外）

- 助詞：に・を・が・は・で・と・へ・の・も・から・まで・より
- 助動詞・補助動詞・活用の続き：た・ない・ている・いく・いる・って・という
- 語の断片（ひらがな複合語も1語扱い）：「どう｜いう」「そう｜いう」「こう｜いう」等
- 漢字熟語・カタカナ語・英単語の途中

**この禁止はカードとカードの境界（カード先頭）にのみ適用する。同一カード内の2行目
（改行後の表示）は境界ではないため対象外**（例：「今何が一番変わったな／っていう感じが
しますか」の2行目「って」始まりは、カード境界ではないので許容される）。

## 連語（コロケーション）はカードをまたがせない

名詞＋助詞＋動詞などで1つの意味になる決まり文句は、途中でカードを割らない：

```
印象に残る　気に入る　身につける　お世話になる　目にする
```

例：「一番印象に残っていること」は必ず1カードに収める。字数が超えるなら
「一番印象に｜残っていること」と2行1カードにして、カード自体は割らない。

## カードの最小文字数

**6文字未満の断片カードを作らない。** 「はい」「先生自身」等の短い相槌・前置きが
単独でこの下限を下回る場合は、前後どちらか自然な方の隣接カードに吸収する
（多くの場合、直後に続く発話の先頭に付けて1カードにする）。吸収先の行が16字を
超えても、6文字未満の断片カードを作るよりは優先する（2026-07 とく歯科案件で確定運用）。

## 分割確定前の機械チェック（レンダリング前に必須）

全カードを対象に、以下が **0件** になるまで境界を引き直して再スキャンする：

1. 隣接カードの末尾/先頭を突き合わせ、単語・熟語・カタカナ語・活用途中の分断が無いか
2. カード先頭の実際の語（word 単位、1文字の部分一致ではない）が上記NGリストに該当しないか
3. 各カードを単独で読んで意味が通るか（通らなければ境界を修正）
4. 6文字未満の断片カードが無いか
5. 1行が16字（横インタビュー等・ルートにより閾値は上表参照）を超えていないか

1件でも見つかったら該当カードの境界を引き直し、再スキャンしてから焼き込みに進む。

## 2行化のときの考え方

1 chunk を2行に割るのは、**単なる字数折返しではなく「情報追加の場」**として使うことがある：

- 「ぼくもその方も今年の2月」
  → 「ぼくもその方も非エンジニアで／今年の2月」
  （"非エンジニアで" を足して「未経験でもできた」を強調）

逆に、字数だけで割らざるを得ない時は **前半＝状況／後半＝オチ・感情** の構成にする：

- 「結婚して住んでるけど／帰りたいやろ？」
- 「目標まであと3ヶ月／ワクワクしてる」

## 「ぐらい」「とか」の取り扱い

投稿者の曖昧表現は **基本そのまま残す**（特に医療数値・時間・人数）。

| NG（断定化） | OK（曖昧表現を残す） |
|---|---|
| 200ml 抜いてもらって | 200ml ぐらい 抜いてもらって |
| 2センチに収まってた | 2センチぐらいに収まってた |
| 1時間でできちゃいました | 1時間ぐらいでできちゃいました |
| この2週間は | この2週間ぐらいは |

ただし、明らかに口癖でしかない「ぐらい」「とか」は削っていい（例：「ちょっと見て」の「ちょっと」は削除可）。判断基準：**数値・量・時間に関わるなら残す**、語り口の調子なら削ってよい。

## フィラー除去

| 削る | 残す |
|---|---|
| いやー / まあ / っていうか / あー / えーっと | なんか（リズム）／もう（強調） |
| ですから（文頭） / っていう（後置） | やん / やべー / めっちゃ |
| ですね（語尾連発時） | よね（自然調の語尾） |
| こう（指示語連発） | — |

## 重複語の刈り込み

前 chunk で既出の語は次 chunk で省く：

- 前：「スタバ500円」
- 次：~~「スタバの500円フラペチーノ」~~ → 「フラペチーノ飲むために」

## 列挙の圧縮

- 「東京なんですか名古屋なんですか福岡なんですか」
  → 「東京でも福岡でもない」（言い切り）

## オチに不要な末尾カット

- 「高い橋代怒られる」→ 「高い橋代」
- 「〜なんですよね」→ 「〜なんですよ」or「〜ですよ」

## 句読点

- **縦リール：句読点（、。）を付けない**
- **横講座（YouTube）：「、」「」「？」を付ける**（読みやすさ優先）

## まとめ：チェックリスト

字幕を出す前に必ず確認：

- [ ] 1行 ≤ 12文字（快適）／ 15文字超は2行化
- [ ] cps ≤ 7（>12 は不可）
- [ ] 行頭NG文字を回避
- [ ] カタカナ・英数字・数字・固有名詞の途中で割っていない
- [ ] 「ぐらい」「とか」を数値文脈で勝手に削っていない
- [ ] 句読点（縦は無し・横は有り）
- [ ] 一人称・文体は投稿者の好みに合わせる（spec で確定）
- [ ] 文脈依存の誤変換（コルトレーン／リンパ腫／Claude Code 等）を直した
