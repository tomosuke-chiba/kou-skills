# context-corrections.md — 文脈依存の誤変換補正

Whisper の誤変換のうち **辞書では直せず、AI の文脈理解が必要なもの** を集めたメモ。

## 鉄則

1. 辞書（vocabulary.json）の `corrections` は **既知のパターン置換**だけを担う（クロード→Claude、ジェミニ→Gemini など）
2. 文脈依存の誤変換は **AI が動画の話題を読み取って判断するしかない**
3. 「辞書ヒット0件＝問題なし」と都合よく解釈しない（オオカミ少年化を防ぐ）

### サイト・アプリの混同（制作者固有）

制作者によっては「サイト」「学習サイト」「学習アプリ」「LP」「商品ページ」「講座」「コース」を流動的に使う。発話そのままだと「サイト」連呼で視聴者が混乱する → **テロップでは文脈ごとに使い分ける**：

| 発話 | テロップでの推奨 |
|---|---|
| 「学習サイトとかアプリ」 | 学習アプリ |
| 「こういうサイト」（商品LP の文脈） | 商品ページ／LP |
| 「動画コース」 | 動画コース（そのまま） |
| 「講座を販売」 | 講座（そのまま） |

## チェックの仕方（AI 側）

字幕を確定する前に：

1. 動画全体の話題を1行で要約（「ジャズ学習アプリの紹介」など）
2. 全テロップを意味で読み直す
3. 話題と矛盾する固有名詞・専門語があれば誤変換を疑う
4. 同音異義は文脈で正しい方を選ぶ
5. 確定できないなら **テロップから消すか、確定できる別の語で言い換える**（盛らない・捏造しない）

## やってはいけないこと

- 「辞書にあるからこれは大丈夫」と機械的に通す
- 不確かなまま「Claude Code」と書く（実際は単に「Claude」だったかも）
- 数字・固有名詞を盛る（「500人」→「5000人」NG）
- 発話の意味と違うテロップを書く（自分の解釈で書き換える）

## 独立検証

最終的なテロップは **同じ AI セッションで自己採点しない**（自己循環）。別プロセス（Codex を別起動して検証させる・別エージェントを立てる）で：

- 「テロップが発話の意味を歪めてないか」
- 「医療数値・人数・固有名詞が正確か」
- 「曖昧表現（ぐらい）を勝手に削ってないか」

を確認する。これが **教科書の核心の品質保証**。
