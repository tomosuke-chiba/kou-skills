# slide-message-architect

話し言葉、台本、文字起こし、企画書などを、最適なスライド枚数と「1枚1メッセージ」の制作表へ変換するCodex Skillです。

## 主な用途

- 内容を何枚のスライドに分けるべきか判断する
- 各スライドの役割、結論、最終表示文言、強調箇所を確定する
- 比較・因果・手順・証拠など、メッセージに合う視覚構造を指定する
- 承認済み設計を `blue-gradient-slide-generator` へ引き渡す

## 入出力

- 入力: 台本、文字起こし、メモ、長文資料、参考スライド
- 出力: 推奨枚数と、スライドごとの役割・メッセージ・表示文言・視覚指示を含む制作表

## 品質の要点

- 1枚につき、観客の認識変化を1つに限定する
- 表示文言を完成形で書き、プレースホルダーを残さない
- 隣接スライドで同じ説得役割を繰り返さない
- 明示的な評価だけを再利用可能な学びとして記録し、機密情報や個人情報は保存しない
