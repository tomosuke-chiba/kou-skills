# Output contract

Lead with:

`推奨は **N枚構成** です。`

Follow with one short paragraph explaining the count boundary. Then provide this table. Use `<br>` inside cells when needed.

| # | 🎯 スライドの役割 | 💬 ワンメッセージ | 📝 最終表示文章 | ✨ 強調語 | 🖼️ 図解・見せ方 | 🔗 前後のつながり |
|---|---|---|---|---|---|---|

For `最終表示文章`, include all applicable fields exactly as they should appear:

- `タイトル：`
- `サブタイトル：`
- `カード／本文：`
- `結論：`

Rules:

- Write actual final copy, not editorial descriptions.
- Quote user-mandated text exactly.
- Limit the title to one sentence and avoid line breaks unless the user requests them.
- Limit emphasized phrases to one through three.
- Specify a concrete layout: left-right comparison, three-card sequence, cause-effect, circular loop, or one-message hero.
- Include important icons or line-art subjects, arrow direction, relative size, and dominant focal point.
- Use concise emoji only in table structure or role labels; do not decorate every sentence.

End with a short sequence summary such as:

`疑問 → 難しさの理解 → 解決方法 → 再現性 → 将来価値`
