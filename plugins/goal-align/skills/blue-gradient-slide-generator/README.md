# blue-gradient-slide-generator

承認済みのスライド設計から、KOUのコバルト〜シアンのビジュアルシステムに沿った16:9 PNGを生成・検証するCodex Skillです。

## 主な用途

- 承認済み構成から完成スライドPNGを作る
- メッセージの関係性に合わせて、標準・カスタム・ハイブリッド構図を選ぶ
- 既存スライドの局所修正または再生成を判断する
- 明示的な視覚フィードバックから再利用可能な設計原則を学ぶ

## 入出力

- 入力: 承認済みスライド設計、文字列台帳、参考画像
- 出力: バージョン管理されたPNG、正規化プロンプト、品質検証結果

## 品質の要点

- ヘッダー比率14〜16%を機械検証する
- 表示文字列を文字単位で台帳と照合する
- 3秒で関係性が伝わるか目視確認する
- 明示的に承認された非機密画像だけを正例へ登録する

詳細は [SKILL.md](SKILL.md) を参照してください。
