# Align → DoD → Solve（オーケストレータ）

> 構成: `grill-me`（認識合わせ）→ 地図→4要素変換 → `dod`（完了定義）→ ［明示指示時のみ］`kinoshita-solution`（4案展開）

## 原則

- 既存3スキルの手順を書き換えない。このスキルは**順序と受け渡しだけ**を定義する
- **重複質問の禁止**: grill-me の地図で確定済みの項目を dod で聞き直さない
- grill-me の停止境界（同一チャットで実装しない）を全フェーズに継承する

## 手順

1. **Phase 1 — grill-me**: Skillツールで `grill-me` を起動し、手順どおり完遂する（地図1ファイル化・teach-back 含む）
2. **Phase 2 — 地図→4要素変換**: 確定した地図から dod の4要素へ自動変換する

   | dod の要素 | 地図の対応箇所 |
   |---|---|
   | 目的 | ゴールの上位目的 |
   | 目標 | ゴールの「XからYへ」＋期限 |
   | 答えの条件 | 完成条件を「〜になりさえすればいい」の1文に言い換え |
   | 検証方法 | 進捗指標・証跡・判定者 |

   変換結果を表で提示し、**地図から埋まらない要素だけ**質問する（未確定の数値は推測で置かず「❓要確認」）
3. **Phase 3 — dod 確定**: `dod` スキルの出力形式（重タスク=4要素表／軽タスク=2行）で確定し、**ここで一旦停止する**
4. **Phase 4 — kinoshita-solution**: ユーザーが「ソリューションも」「4案出して」「木下式で解を」と明示指示した場合のみ `kinoshita-solution` を起動する。指示がなければ展開しない

## 停止境界

- DoD確定＝このスキルの既定の完了点。ソリューション展開・実装・公開・コミットは別指示
- grill-me 同様、同一チャット内での実装は禁止
