# grill-me

Googleマップ型の壁打ちで、現在地、ゴール、ルート選択、進捗指標、期限、前提・制約を共通認識へ揃え、テーマ単位の1ファイルへ蓄積するスキル。

## 中核

- 現在地は、基準値、既存資産、過去施策と結果、関係する役割、ボトルネック、未確認事項まで調査する
- ゴールは原則として `XからYへ、期限までに` とし、難しい場合は代理指標・観測条件・学習ゴールを使う
- ルートを選ぶ評価基準と、ルートを進んでいるか測る指標を分ける
- 事業・WIG文脈では、遅行、先行、ガードレール、スコアボード、実行リズムまで深掘りする
- 同じテーマでは最新地図と判断履歴を1ファイルで更新し、生の会話ログや人物プロファイルを残さない
- 重要案件では地図確定後にTeach-backを行い、通過後も同じチャットでは実装しない

詳細な実行手順は `SKILL.md`、成果物・質問・評価契約は `references/handoff-contract.md`、事業・WIG固有の設計は `references/business-wig-map.md` を参照する。
